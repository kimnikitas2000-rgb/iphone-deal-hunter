# iPhone Radar 1.3 — Telegram Mini App

Telegram Mini App + бот для поиска реальных объявлений iPhone на Avito, оценки относительной выгоды и отправки уведомлений. Демонстрационных карточек нет.

## Главное изменение в 1.3

**Бизнес-аккаунт Avito и `ADS_API_USER` / `ADS_API_TOKEN` больше не нужны.** По умолчанию сервер запрашивает публичную HTML-страницу поиска Avito и извлекает карточки, если площадка отдаёт их без авторизации. Для каждой карточки требуется прямая ссылка Avito с ID, иначе запись исключается.

Публичная выдача может ограничивать автоматические запросы, менять HTML или требовать проверку. Приложение не обходит CAPTCHA, авторизацию, блокировки или иные ограничения доступа. В случае отказа данные не выдумываются: интерфейс показывает ошибку и пустую ленту.

Если прямая публичная выдача недоступна, можно подключить **ReefAPI** — сторонний read-only провайдер, не требующий входа или бизнес-аккаунта Avito. У него отдельный ключ и собственные лимиты/условия; документация и пробный доступ: https://reefapi.com/docs/avito. Сайт ReefAPI указывает стартовый лимит 1 000 бесплатных кредитов без привязки карты, но перед использованием проверь актуальные условия.

## Источники объявлений

### Вариант A — без ключей (по умолчанию)

В `.env` оставь или укажи URL публичного поиска Avito:

```env
AVITO_PUBLIC_SEARCH_URL=https://www.avito.ru/all/telefony?q=iPhone
```

Можно вставить собственную публичную URL-выдачу Avito с выбранным городом и фильтрами. Сервер будет опрашивать эту страницу с ограничением частоты и извлекать карточки, доступные в HTML. В зависимости от того, что Avito отдаёт серверному запросу, результаты могут быть неполными или запрос может быть отклонён.

### Вариант B — сторонний источник без бизнес-аккаунта Avito

1. Создай ключ ReefAPI по инструкции на https://reefapi.com/docs/avito.
2. Укажи его в `.env`:

```env
REEFAPI_KEY=твой_ключ_reefapi
# Необязательно: slug города, например moskva. Пусто — поиск по России.
REEFAPI_LOCATION=
```

Если ReefAPI настроен, он используется первым. При ошибке сервер попробует публичную выдачу Avito. Если оба источника недоступны, приложение сообщит об ошибке.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
cp .env.example .env
npm test
npm run check
npm start
```

Открой `http://localhost:3000`. Для входа в Mini App и уведомлений понадобятся `BOT_TOKEN` из `@BotFather` и публичный HTTPS адрес `WEBAPP_URL`. Они не нужны для самой функции парсинга, но необходимы для Telegram-авторизации, бота и доставки уведомлений. Сервер в текущем архиве построен на `node:http` (не Express).

В `.env` доступны:

- `BOT_TOKEN` — токен Telegram-бота.
- `WEBAPP_URL` — публичный HTTPS адрес Mini App.
- `AVITO_PUBLIC_SEARCH_URL` — публичная поисковая URL Avito; ключи Avito не нужны.
- `REEFAPI_KEY` — опциональный ключ стороннего API, не связанный с бизнес-аккаунтом Avito.
- `REEFAPI_LOCATION` — опциональный slug города для ReefAPI.
- `PORT=3000` — порт веб-сервера.
- `POLL_INTERVAL_MINUTES=5` — интервал фонового опроса, минимум 5 минут.
- `TELEGRAM_AUTH_MAX_AGE_SECONDS=86400` — максимальный возраст Telegram `initData`.
- `DATA_DIR=./data` — каталог локального JSON-хранилища.

## Логика и защита качества данных

- Загружаются только объявления, в заголовке или описании которых найдено `iPhone` / `айфон`.
- Цена должна быть положительной.
- URL должен вести непосредственно на карточку Avito с ID, главная страница и поисковая выдача не используются вместо неё.
- При HTTP 403/429, CAPTCHA или неизвестной разметке ошибка не подменяется фиктивными карточками.
- Частота запросов ограничена, ответы кэшируются; код не использует прокси-ротацию, CAPTCHA-сервисы или обход входа.
- Рыночные ориентиры из `src/market.js` — запасные оценки. Медиана по найденным похожим предложениям надёжнее при достаточном количестве карточек.

## Telegram

1. Создай бота через `@BotFather` и внеси `BOT_TOKEN` в `.env`.
2. Размести приложение на сервере с постоянным HTTPS URL и задай `WEBAPP_URL`.
3. Укажи домен Mini App в настройках бота.
4. Перезапусти сервер и проверь `https://твой-домен/health`, затем отправь `/start` боту.

Для production используй HTTPS. Не публикуй `.env` и не коммить токены. На одном токене не следует запускать несколько экземпляров long-polling бота одновременно.

## Тесты

В тестах используются локальные HTML/JSON fixtures. Они проверяют разбор карточек, фильтр прямых ссылок, работу без `ADS_API_USER` / `ADS_API_TOKEN`, опциональный ReefAPI и корректное поведение при HTTP 403. Тесты не делают реальных сетевых запросов к Avito и поэтому не доказывают, что площадка прямо сейчас отдаёт HTML конкретному серверу.
